# Codex for Android artwork

The project icon and social preview were generated with the built-in image
creation tool. They use a mint-teal phone frame, a white terminal prompt, and a
charcoal background. They do not use the OpenAI logo or Android robot.

Files: `icon.png`, `social-preview.png`, and its JPEG upload copy
`social-preview.jpg` (converted with macOS `sips` to meet GitHub's 1 MB limit). These are community project branding,
not an Android APK launcher icon. Both selected outputs are saved in this
repository; the social preview used `icon.png` as its visual reference.

## Icon prompt

Use case: logo-brand. Create a finished square application/project icon for
'Codex for Android', a community command-line coding tool running in Termux on
Android. A striking but restrained premium developer-tool mark: centered upright
smartphone silhouette with softly rounded corners, built from clean precise
geometric shapes, containing a bold terminal prompt >_ in its screen. Deep
charcoal rounded-square tile, luminous mint-teal phone frame, crisp warm-white
terminal glyph, subtle restrained depth and a very faint teal glow. Strong large
silhouette, generous negative space, flawless small-size legibility. Flat
vector-like design with tasteful dimensional polish, no mockup, no surrounding
objects. Square composition, icon occupies about 65% of canvas. No words, no
letters beyond >_, no Android robot, no OpenAI knot logo, no official-company
marks, no watermark. Produce one polished 1024x1024 PNG icon. Save the generated
image for use in the project.

## Social preview prompt

Use case: logo-brand. Create a polished GitHub repository social preview banner
for Codex for Android. Use the attached phone/terminal icon as the exact brand
reference: retain its mint-teal frame, white >\_ prompt and charcoal rounded-square
tile. Wide landscape 2:1 composition, intended 1280x640 pixels. Place the icon at
the left with generous margins, substantially smaller than the canvas. On the
right use clean beautiful modern sans-serif typography with the exact large
white title 'Codex for Android' and exact smaller muted teal subtitle 'Your coding
agent. In Termux.' Below place small muted gray text 'Community project · ARM64
Android'. Deep charcoal background with a subtle restrained teal light around
the icon; plenty of negative space, excellent readability, premium developer-tool
aesthetic. No Android robot, no OpenAI logo, no extra words, no browser chrome,
no mockup, no watermark. Deliver one complete finished landscape banner.
